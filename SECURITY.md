# Security

Please **don't** open a public issue for a security problem.

Report it privately: repository **Security** tab → **Report a vulnerability**
(GitHub private vulnerability reporting). You'll get an answer within a week.

Things we especially want to hear about:
- Another web page or program being able to use the dashboard's API (it should answer only the
  dashboard on this PC).
- Anything that makes Companion touch the game beyond capturing its window.
- A leaked Discord webhook or other secret.

Only the latest release is supported.
